# Smart Data Analyzer

A GUI-based desktop application built with Python that enables business users to analyze Excel and CSV data without writing code.

## 🎥 Demo Video

A complete walkthrough of the Smart Data Analyzer application is available below:

[📥 Download Demo Video](./demo%20video%20zip/Demo%20Video%20Smart%20Data%20Analyzer.zip)

The demo showcases:
- File Selection & Reading
- Dynamic Column Detection
- Report Generation
- Data Visualization
- Report Export
- Chart Export
  
## Features

* Import Excel and CSV files
* Automatic detection of text and numeric columns
* Dataset summary:

  * Total rows
  * Total columns
  * Column names
* Dynamic GroupBy reporting
* Aggregations:

  * Sum
  * Average
  * Count
  * Max
  * Min
  * Median
* Interactive chart generation:

  * Bar Chart
  * Column Chart
  * Line Chart
  * Pie Chart
* Export reports to Excel or CSV
* Export charts as PNG

## Technologies Used

* Python
* Pandas
* Tkinter
* Matplotlib
* OpenPyXL

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python smart_data_analyzer.py
```
